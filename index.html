In Development · Personal Project
Intellio
Multi-Agent AI Analytics Platform · Mortgage & Finance Intelligence
Why I Built This
  • Finance teams spend hours manually analyzing files across Excel, SQL, and dashboards.
  • Intellio replaces that with AI-driven analysis, built-in mortgage domain knowledge, and instant answers from raw data.
  • The goal: make advanced analytics usable by business users without sacrificing governance, privacy, or accuracy.

Built entirely from scratch on personal time using public data — Intellio is a full-stack, production-grade analytical platform for mortgage and finance professionals. Users connect their own data files, let AI auto-label every column, build a domain knowledge base of business rules and formulas, then ask natural language questions that return schema-aware SQL, automated charts, and executive-ready answers.

Features a Python sandbox agent for code-based analysis with file exports, local LLM support via Ollama for privacy-sensitive workflows, and ships as both a web app and a native desktop app via Tauri v2. The mortgage domain knowledge injection engine ensures answers respect weighted average formulas, DQ rate definitions, and UPB conventions automatically.
